### 固定“不可直接比较”的边界

模型包含未售产出，尚未实现经过论证的 BEA 支出法 GDP 映射；单商品交易价格也不是经过验证的 PCE 消费篮子。PNFI 是明确选定的**经济参考口径**，不是对模型资本融资方式的现实有效性认证。

因此，这些项不再含糊地标成“口径可能不同”，而是在契约中明确为 `non_comparability_frozen`。本轮不拿这些尚不可直接比较的量构造真实拟合通过判定。以后改变经济映射需要独立版本，不回改本轮结果。

## 2. 可释放参数与基础条件

只释放 `price_adjustment_speed`，范围 0.15–0.25。其他参数固定：

- `capital_adjustment_speed = 0.20`；
- `inflation_expectation_lambda = 0.50`。

固定值是参考值，不是可靠估计值。原因是前轮发现目标资本上限分支中投资速度代数抵消、预期传导截断，且两者响应可能混淆。

选择两组价格参数曾通过局部筛查的基础条件：

1. 主条件：协作者默认，alpha=0.36、delta=0.06、初始 K/Y 不人为指定，保留财富减政府债务的初始化。
2. 次条件：私人非住宅代理，alpha=0.36、delta=0.08392250548581576、K/Y=1.2924260047334994。保持与已打开的局部筛查相同，不换为新的期初分母后冒称继承旧识别结果。

N=256、8 期；评价 t2–t8，排除初始化 t1。这些是合成时期，不映射为真实 2023–2030 年。未扩大到 N=1000 或其他未经本轮设计覆盖的基础条件。

## 3. 重复搜索设计

| 项目 | 冻结值 |
|---|---|
| 两个合成真值 | 价格速度 0.175、0.225；分别检验低于／高于默认值的目标 |
| 目标样本 | 每个基础条件、每个真值各 64 seeds |
| 候选网格 | 0.150、0.175、0.200、0.225、0.250，包含默认值和两个真值 |
| 重复搜索 | 每个基础条件 6 个互不重叠的 16-seed 搜索池 |
| 比较重复数 | 每池前 2、前 8、全部 16 seeds；同一网格、同一目标 |
| 独立验证 | 每个基础条件 64 个新 seeds，预先规定评价全部五个候选 |
| 调用预算 | 74 次批量调用，1,856 条物理模拟路径，576 个不同 seed 值 |
| 保留规则 | 任何无效路径、核算失败、源码漂移都停止，不删除失败 seeds 后继续计分 |

同一搜索池内，各候选使用相同 seeds，即共同随机数配对。跨角色、跨搜索池、跨基础条件种子不重叠。2/8/16 为嵌套样本，不是三批独立实验；各重复共享目标与验证池。因此，六次重复表示**给定目标和验证池时的搜索随机性**，不能把验证样本数乘以六。

全部基础条件、真值和搜索池的选择结果保存到 `selections_before_validation.json` 后，才运行任何验证路径。验证网格的最优项只用于有限网格 regret 诊断，不反馈为新推荐参数。

## 4. 评价指标与区间

搜索损失为平均轨迹相对合成目标的四轴归一化 RMSE，四轴尺度沿用 0.01、0.02、0.05、0.03。损失差不超过 1e-12 时优先最接近默认 0.20 的参数，再取较小值。

主要报告：

- 六次搜索的选中频数、众数比例和平均参数误差；
- 候选排序的两两一致程度；
- bootstrap 候选歧义集合大小；
- 独立验证损失、相对默认值的配对差、有限网格 regret；
- 平均路径 MAE 和逐 seed 四轴 MAE 同时通过比例；
- 目标池前／后 32 seeds 的均值差，检查目标本身的抽样波动。

bootstrap 以**完整 seed 轨迹**为单位，同时对候选作相同索引重采样，目标池独立重采样。搜索 400 次、验证 1,000 次。候选歧义集合保留相对已选项的损失差 2.5% 分位数不大于零的候选。

这里的 95% 百分位区间是逐比较、探索性区间，**没有同时覆盖或选择后覆盖保证**。2-seed bootstrap 尤其不能视为可靠总体不确定性估计。不新增一个未经校准的“强识别 PASS”标签。

## 5. 能够支持与不能支持的结论

本轮可以判断：缩到价格参数后，候选排序／选择是否更稳定；增加种子数是否改善条件性选择；是否存在候选不唯一但输出误差相近的情况。

本轮不能证明：现实经济预测能力、三参数联合识别、某优化算法等预算优越性、跨模型泛化，或目标与验证抽样全部积分后的总体成功率。两真值均在有限网格内，这是有利的可实现性测试，不是开放域优化难题。

下一门依据本轮结果决定，不根据结果追改本契约、搜索网格、阈值或基础参数。若不稳定，先区分目标噪声、搜索噪声、观测映射和离散网格分辨率，再讨论优化器。
