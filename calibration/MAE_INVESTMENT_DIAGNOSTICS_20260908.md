## 2. 独立 MAE 验收的明确含义

设 m 为观测轴、t 为合同指定时期、s 为预先指定的模拟种子。模块分别计算：

```text
种子平均路径 MAE(m) = mean_t |mean_s x(s,t,m) - target(t,m)|
逐种子 MAE(s,m)     = mean_t |x(s,t,m) - target(t,m)|
逐种子 MAE 的均值   = mean_s MAE(s,m)
```

三者不能混用：种子平均可能抵消方向相反的随机误差，时间上的有符号误差则不能在取绝对值之前抵消。

当前四轴阈值沿用任务书拟定量级：通胀 .01、GDP 增长 .02、C/GDP .05、I/GDP .03，统一为比例单位。具体调用必须显式提供合同，不从搜索结果自动寻找有利阈值。

输出分为三层：

| 层级 | 输出 | 含义 |
|---|---|---|
| 路径完整性 | `INVALID` 或继续计算 | 指定 seeds、轨迹长度与顺序、有限值、运行失败均检查；不删除失败 seed 后求均值 |
| 宏观平均路径 MAE | 各轴及综合 `PASS/FAIL/NOT_EVALUATED` | 所有四轴可比目标齐备且平均路径 MAE 均达标，才是这一层的 PASS |
| 完整任务书／经济有效性 | 当前始终 `NOT_EVALUATED`／false | 宏观数值通过不替代微观可比性、全部门核算、正式稳定性与历史条件对齐 |

模块还输出逐 seed MAE、逐 seed 达标比例、跨 seed 样本标准差和最小／最大值。单 seed 的标准差为 null，不伪造置信区间；当前也未估计目标样本本身的不确定性。缺某一轴的可比目标时显式使用 null，不能填零后变成通过。当前独立验证只支持第 2 期起，初始化第 1 期不计入独立证据。

## 3. 投资传导：记录什么、在哪个时点记录

| 阶段 | 记录内容 | 检查对象 |
|---|---|---|
| 融资价格 | 当期名义贷款利率、投资决策实际使用的预期通胀、实际利率、资本使用成本 | Fisher 转换及使用成本与折旧的对应 |
| 资本目标 | 当期生产资本、生产率、劳动、目标资本、目标上限、上限处边际产出 | 上限规则及目标资本重建 |
| 投资意愿 | 重置投资、资本缺口、未裁剪投资需求、期望固定投资 | 零下限和净扩张上限 |
| 投资融资 | 期望名义信用、可用信用、融资比例、融资固定投资 | 是否发生实质信贷配给 |
| 商品结算 | 总供给、家庭消费、政府购买、剩余商品、实际固定投资 | 融资投资与剩余商品的最小值 |
| 资本结转 | 期末资本、折旧后资本、实际投资 | 资本转移式 |

共七个残差：实际利率、使用成本、受限目标资本、期望投资、融资映射、商品配给和资本转移。残差尺度记录为对应公式各项绝对值之和，容差 `1e-5 + 1e-10*S`。这是**投资子链的实现一致性**，不是全部经济部门的会计闭合证明，也没有验证银行“可用信用”内部政策本身的经济正确性。

关键时点处理：

- 投资决策使用的预期取 step 之前的值，不用 step 末更新后的下一期预期；
- 名义投资使用当期成交价，不用已经更新为下一期的 `market.price`；
- 使用当期生产资本 `market.Kt`，不误用 step 前尚未提升的旧资本；
- 所有读取在现有状态上完成，没有改协作者源码或插入经济状态补丁。

诊断单独输出 `PASS/FAIL/UNAVAILABLE`。诊断缺字段不会被伪装成通过，也不会改变原模拟路径有效性门。诊断状态与运行状态要分别检查。

## 4. 新开发样本揭示的具体阻断位置

使用 N=256、4 期、3 个新开发 seeds，对默认参数及资本速度 .1、价格速度 .3、预期更新率 .7 分别作成对比较。本次没有再优化候选。

| 设置 | 目标资本上限激活 | 实质信贷配给 | 商品配给约束 |
|---|---:|---:|---:|
| 基线 | 12/12 | 0/12 | 12/12 |
| 资本速度 .1 | 10/12 | 0/12 | 12/12 |
| 价格速度 .3 | 12/12 | 0/12 | 12/12 |
| 预期更新率 .7 | 12/12 | 0/12 | 12/12 |

这里分母为 3 seeds × 4 期，不是独立样本数。仅对这批受控设置成立，不推断所有参数区域都受相同约束。

两条可直接核对的诊断例子：

1. **预期信号被目标资本上限吸收。**seed 908901，第 2 期，将预期更新率从 .5 改为 .7，实际贷款利率变化约 +0.004003（约 +0.4003 个百分点），但目标资本、期望投资、融资投资和实际投资变化均为 0。三个 seeds 的后续预期扰动都没有改变本批次实际投资。这不是参数未传入，而是目标资本仍处于相同的上限分支。
2. **投资需求变化被商品余量吸收。**同一 seed、第 2 期，资本速度从 .2 改为 .1，期望／融资投资减少约 671,321 个模型实物单位，但当期实际投资变化为 0，因为两个配置都受同一商品余量限制。不能把该实物差额写成全国美元金额。

此外，资本上限为 `K * (1 + growth / speed)`，降低 speed 会扩大目标资本上限，不能只看目标资本数值增加就误判“调整变慢导致实际扩张更快”。在上限分支，`speed * (target - K)` 可以仍等于固定净扩张上限。

**当前可以定位的结论是：这批样本中，目标上限和商品约束会压缩参数的可观测作用，融资额度不是已观察到的主要瓶颈。**这比“预期弱识别”更具体，但尚不是全局识别结论，也不是要求移除合理约束的经济学依据。

原始成对差值保存在 [summary.json 的 paired_transmission](runs/mae_investment_v2/summary.json)。完整输入、派生量及逐式残差在每条 `path_seed_*.json` 的 `investment_diagnostic` 中。

## 5. 使用方法与边界

独立 MAE 可直接读取后端保存的 response，不需要重跑模拟器：

```powershell
python -B calibration/mae_acceptance.py --result calibration/runs/mae_investment_v2/baseline/eval_0000/response.json --contract calibration/runs/mae_investment_v2/new_mae_contract.json --output calibration/runs/my_mae_report.json
```

合同必须与该响应的 expected_seeds、horizon、periods 完全匹配。CLI 输出使用新文件，不覆盖旧结果；不同 seed 组或目标需另建合同。目标和阈值可以作为独立测量接口输入，但该模块不开放真实参数优化入口，也不能自行把开发数据升级为确认性证据。

普通 `launch.py evaluate` 现在会自动记录投资诊断，模拟器和原有效性标准不变。整体回归可用 `check_mae_investment_runtime.py`，它会实际运行 14 条开发路径，必须指定新输出目录。

下一步优先用这些日志确定能提供有效参数响应的开发设置，并增加目标／搜索样本以评估随机波动；尚不应仅因当前受限就修改协作者资本上限或商品约束。若真实口径、全部门核算或历史政策需要上游变更，仍逐项讨论。
